# 🎓 PaperPredict AI: Exam Question Predictor & Model Paper Generator

An AI-powered academic prediction platform built for Indian board examinations (CBSE Class 10 & 12). PaperPredict analyzes historical recurrence cycles from 6+ years of previous year question papers (PYQs), generates statistical probability scores for upcoming exam topics, and produces authentic predicted model papers matching official blueprints.

---

## 🌟 Key Features

* **6-Year Historical Recurrence Engine:** Evaluates alternate-year rotation cycles, mandatory staple topics, and unit marks distribution.
* **Dual Question Sourcing Modes:**
  * **Option 1: Autonomous Web & Master Archive:** Automatically queries official CBSE archives, Kendriya Vidyalaya pre-board databases, and verified 6-year PYQ repositories.
  * **Option 2: Student Upload with Consent:** Upload custom school pre-board papers or state board tests (PDF / camera photos). Includes a clear community archive disclaimer to ethically enrich training data without saving personal student information.
* **Product-Led Growth (1-Time Free Subject Sample):** Students get 1 complete subject 100% free with all questions, full derivations, and step-by-step examiner marking schemes unlocked.
* **Micro-UPI Monetization (₹49 / ₹149):** Low-friction payment gate via PhonePe, Google Pay, and Paytm for additional subjects or all-subject board passes.
* **Official CBSE Blueprint Layout:** Simulates complete examinations across Section A (MCQs & Assertion-Reason), Section B (Very Short), Section C (Short), Section D (5-Mark Derivations), and Section E (50% Competency Case-Studies).
* **1-Click Printable A4 / PDF Export:** Clean, distraction-free examination view formatted for printing or saving as PDF for timed mock practice.

## 🛠️ Tech Stack

* **Framework:** Next.js 16 (App Router, Turbopack)
* **Library:** React 19, TypeScript
* **Styling:** Tailwind CSS v4
* **Icons:** Lucide React
* **Persistence:** Browser LocalStorage (Zero-server friction)

## 🚀 Getting Started

### 1. Clone the Repository
```bash
git clone https://github.com/Sada23112/paper-predict.git
cd paper-predict
```

### 2. Install Dependencies
```bash
npm install
```

### 3. Run the Development Server
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
